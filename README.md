# مدیریت جایگاه سوخت

یک PWA تک‌صفحه‌ای برای مدیریت روزانه جایگاه سوخت، با رابط کاربری فارسی و RTL.

## ویژگی‌ها

- ورود با نام کاربری پیش‌فرض: `admin` و رمز عبور: `1234`
- تنظیمات ظرفیت مخزن، ظرفیت تانکر، قیمت تانکر و هزینه هر لیتر سوخت
- نمایش تاریخ شمسی و ساعت زنده
- ورود روزانه موجودی و فروش‌ها با محاسبات خودکار
- گزارش روزانه، حذف رکورد و خلاصه ماهانه
- ذخیره‌سازی داده‌ها در localStorage
- خروجی و ورودی CSV با BOM UTF-8
- پشتیبانی از حالت تاریک/روشن
- قلم Vazirmatn از CDN گوگل
- واکنش‌گرا و مناسب موبایل
- قابلیت نصب و استفاده آفلاین به لطی Service Worker

## فایل‌ها

- `index.html` — برنامه اصلی
- `manifest.json` — مانیفست PWA
- `service-worker.js` — کش فایل‌ها برای آفلاین
- `README.md` — همین فایل

## نحوه اجرا محلی

فایل‌ها را در یک پوشه قرار دهید و یک سرور محلی راه بیندازید:

```bash
python3 -m http.server 8080
```

سپس مرورگر را باز کنید:

```
http://localhost:8080
```

## استقرار در Netlify

1. به [netlify.com](https://netlify.com) بروید و وارد شوید.
2. از داشبورد، **Add new site > Deploy manually** را انتخاب کنید.
3. پوشه شامل سه فایل (`index.html`, `manifest.json`, `service-worker.js`) را آپلود کنید.
4. Netlify یک آدرس عمومی مانند `https://example.netlify.app` به شما می‌دهد.
5. برای به‌روزرسانی، فایل‌های جدید را دوباره آپلود کنید.

## استقرار در GitHub Pages

1. یک مخزن جدید در GitHub بسازید.
2. سه فایل `index.html`, `manifest.json` و `service-worker.js` را در مخزن push کنید.
3. در مخزن، به **Settings > Pages** بروید.
4. در بخش **Build and deployment**، **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` (یا `master`) را انتخاب کرده و ذخیره کنید.
6. پس از چند دقیقه، سایت در آدرسی مانند `https://USERNAME.github.io/REPO-NAME` قابل دسترس خواهد بود.

## نکات فنی

- برنامه به localStorage مرورگر نیاز دارد؛ در مرورگرهای خصوصی (Private) ممکن است داده‌ها پاک شوند.
- service worker فقط روی HTTPS یا localhost فعال می‌شود.
- برای نصب روی موبایل، پس از باز کردن سایت، گزینه «Add to Home Screen» را انتخاب کنید.

## تماس و توسعه

می‌توانید تنظیمات پیش‌فرض را در ابتدای بخش JavaScript فایل `index.html` تغییر دهید یا ظاهر برنامه را در بخش CSS ویرایش کنید.
